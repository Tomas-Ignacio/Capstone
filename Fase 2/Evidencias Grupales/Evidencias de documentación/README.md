# Evidencias de documentación

Esta carpeta reúne documentación técnica y de gestión para la entrega final de **Finanzas App**. El proyecto fue realizado de forma individual por Tomás Ignacio García Barria.

## Contenido

- `ARQUITECTURA_Y_TECNOLOGIAS.md`: componentes, responsabilidades y límites de la solución.
- `MODELO_DE_DATOS.md`: entidades locales, relaciones y decisiones de persistencia.
- `METODOLOGIA_Y_CALIDAD.md`: trabajo visualizado con Kanban, control de cambios y estrategia de calidad.
- `REFERENCIAS_TECNICAS.md`: fuentes técnicas utilizadas.

La documentación describe el estado real del MVP: aplicación Android local, persistencia SQLite y lectura de notificaciones de **Banco Demo** únicamente.
